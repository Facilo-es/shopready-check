# Security

## Reporting a vulnerability

Please tell us privately: open the Security tab of https://github.com/Facilo-es/shopready-check and choose "Report a vulnerability".

Please include the add-on version, your Blender version, and the steps to reproduce the problem. Do not post details in a public issue before we have replied.

We fix confirmed problems in a new release and say so in the release notes.

## What the add-on does and does not do

ShopReady Check has no network code. It makes no connections, sends no data and has no licence server. It only reads your scene and the image files your materials use, and never writes or changes them.
